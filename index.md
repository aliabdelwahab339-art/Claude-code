## Quick Reference: Hormozi Playbook Map

If you're building or scaling a business, use this sequence:

1. **Offer** → `100m_offers` — Build something people desperately want
2. **Audience** → `branding` — Create the right associations before you scale
3. **Leads** → `100m_leads` — Master the Core Four advertising methods
4. **Ads** → `goated_ads` + `hooks` — Build a volume-based creative machine
5. **Nurture** → `lead_nurture` — Get more leads to show up and buy
6. **Close** → `closing` — Convert Maybes into buyers
7. **Proof** → `proof_checklist` — Make strangers believe you instantly
8. **Monetize** → `100m_money_models` + `ltv` + `fast_cash` — Extract maximum value
9. **Retain** → `retention` — Keep what you acquire
10. **Scale Ops** → `marketing_machine` — Remove yourself from the ads
